# Inkshot Arena

A top-down arena shooter in a single HTML file. Ink blobs crawl in from the edges of the print sheet; shoot them, grab ammo crates for bigger guns, and survive as many waves as you can. Every fifth wave brings a boss.

## Play

Open `index.html` in any modern browser. No build step or install needed.

## Controls

| Input | Action |
| --- | --- |
| `W` `A` `S` `D` / arrows | Move |
| Mouse | Aim, hold left button to fire |
| `Space` / `Shift` / right click | Dash (you can't be hit while dashing) |
| `1`–`5`, `Q` / `E`, mouse wheel | Switch gun |
| `P` / `Esc` | Pause |
| `M` | Sound on/off |

On a phone: left thumb moves, right thumb aims and fires, and the Dash button sits bottom right.

## Guns

1. **Pistol**: unlimited ammo
2. **Scatter**: 8-pellet shotgun
3. **Buzz**: fast-firing SMG
4. **Rail**: pierces through every enemy in a line
5. **Boomer**: explosive grenade launcher

Ammo crates drop from enemies and appear after each cleared wave. Chain kills quickly to raise your score multiplier (up to ×8); taking a hit resets it.
